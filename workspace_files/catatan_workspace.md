# Workspace File Agent

Folder ini adalah ruang kerja bersama antara **lu** dan **NusaOperator Agent**:
- **Input Data**: Upload atau simpan file `.json` / `.csv` / `.txt` (seperti `profil_pengajuan.json`) untuk diisi otomatis ke formulir web.
- **Output Riset**: Agent bisa merangkum informasi dari berbagai website lalu menyimpannya ke file `.md` atau `.csv` di sini.
- **Download Otomatis**: Semua file yang di-download di dalam Cloud Browser otomatis tersimpan ke folder ini.
